## Setup by client

### Claude (claude.ai and Claude Desktop)

Works on Free (one custom connector), Pro, Max, Team and Enterprise.

1. Settings, then Customize, then Connectors. On Team and Enterprise an Owner adds it once under Organization settings, Connectors.
2. Click **+**, then **Add custom connector**. Name it `Sprites` and paste `https://mcp.sprites.ai/mcp`. Leave Advanced settings empty.
3. Click **Connect**, sign in to Sprites and approve.

Claude draws the Sprites approval card in the chat, so you can edit a budget or a headline in place and approve it.

### Claude Code

```bash
claude mcp add --transport http sprites https://mcp.sprites.ai/mcp
```

Then type `/mcp` inside Claude Code to finish the browser sign-in.

### ChatGPT

Plus, Pro, Business, Enterprise and Edu, on the web app. Not available on Free.

1. Settings, Security and login: turn on **Developer mode**. On Business and Enterprise an admin has to allow it first.
2. Settings, **Plugins** (formerly Connectors), then **+** to create an app.
3. Name `Sprites`, MCP server URL `https://mcp.sprites.ai/mcp`, Authentication **OAuth**. Tick the trust box and click Create.
4. Connect the app and sign in to Sprites.

### Cursor

`~/.cursor/mcp.json` (every project) or `.cursor/mcp.json` (one repo):

```json
{
  "mcpServers": {
    "sprites": {
      "url": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Cursor discovers the Sprites authorization server from the endpoint and opens a browser to sign in.

### Codex

```bash
codex mcp add sprites --url https://mcp.sprites.ai/mcp
codex mcp login sprites
```

Or by hand in `~/.codex/config.toml`:

```toml
[mcp_servers.sprites]
url = "https://mcp.sprites.ai/mcp"
auth = "oauth"
```

### VS Code and GitHub Copilot

`.vscode/mcp.json`. The top-level key is `servers`, not `mcpServers`, and a remote server needs `"type": "http"`:

```json
{
  "servers": {
    "sprites": {
      "type": "http",
      "url": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Run **Auth** above the entry, sign in, then switch Copilot Chat to **Agent** mode. Ask mode does not call MCP tools.

### Gemini CLI

`~/.gemini/settings.json`. Use `httpUrl`; a `url` entry is treated as SSE:

```json
{
  "mcpServers": {
    "sprites": {
      "httpUrl": "https://mcp.sprites.ai/mcp"
    }
  }
}
```

Restart the CLI; the first call opens the sign-in. Check with `gemini mcp list`.

## What it can read

- Sessions, users, engagement and conversions by any GA4 dimension
- Channel, source, medium and campaign attribution
- Landing pages (organic landing pages included), events and funnels
- Item-scoped ecommerce: revenue and units per product
- Property configuration and linked Google Ads accounts

## What it can change (with your approval)

- GA4 audiences, created from templates (for example "visited pricing but never purchased") or archived
- Ads personalization on a linked Google Ads account, so those audiences reach Google Ads as remarketing lists
- Nothing else in GA4: reports, events and property settings are read-only

Every change arrives as an approval with the before and after. In Claude and ChatGPT it is a card you can edit
in place. In clients without cards, Sprites returns the change written out with a gate id, and applies it only
after you confirm (`approve_change`). Nothing is applied by the model on its own.

## Permissions

- **OAuth.** You connect GA4 once inside Sprites with Google. Sprites requests `https://www.googleapis.com/auth/analytics.readonly` for reports and `https://www.googleapis.com/auth/analytics.edit` for the two writes above (audiences and ads personalization), plus `openid email profile`.
- **Older connections.** A GA4 connection made before the edit scope was added holds read access only. The first write shows a card asking you to grant edit access.
- **No Google Cloud project.** You do not create a service account or OAuth client.
- **Your AI client never holds a Google credential.** It holds a Sprites OAuth token bound to `https://mcp.sprites.ai/mcp`.

## Tools

The server exposes 20 tools to the model: 6 read tools and 14 write tools. Write tools that touch an ad account or a site only propose; nothing reaches either until you approve it. The tools that do the GA4 work:

| Tool | What it does on GA4 |
|---|---|
| `analyze` | Sessions, users, conversions and revenue for any period, with the comparison. |
| `research` | The landing pages, channels and cohorts behind a change. |
| `optimize` | GA4 audiences for remarketing, proposed as approval cards. |
| `run_task` | Anything that crosses GA4 and another channel in one job. |
| `schedule_task` | A recurring brief that arrives without anyone opening GA4. |

GA4 requests use `channel: seo_web` (the schema groups website, Search Console and GA4 there), or `all` when the question spans ad channels too.

Every task tool takes the same input: `goal` (the request written to stand on its own: Sprites sees only this
string, not the chat), `title` (a short label), `channel`, and `today` (the user's local date, so "last 30 days"
resolves correctly). Long tasks return a run id; `task_status` collects the result and `cancel_task` stops it.

## Official server vs this one

**Google Analytics MCP server (googleanalytics/google-analytics-mcp).** Google publishes an official Google Analytics MCP server: reports, funnels, realtime and account summaries. It is read-only, labelled experimental, and runs on your machine with your own Google Cloud credentials.

| | Official / self-hosted | Sprites (this server) |
|---|---|---|
| Where it runs | Your machine, with your Google Cloud credentials | Hosted: paste `https://mcp.sprites.ai/mcp` and sign in |
| Writes | None | GA4 audiences and ads personalization, each an approval card |
| Other channels | GA4 only | GA4 beside Google Ads, Meta, LinkedIn, TikTok, Reddit, Microsoft, Search Console and Shopify |

If you want GA4 reports in a chat and are happy to run a local process, Google's server is the direct route. Use Sprites when the question is which campaign caused the change, or when the answer should become an audience or an ad change.

## FAQ

**Is this a server I have to host?**
No. It is a hosted remote MCP server. Paste `https://mcp.sprites.ai/mcp` into your client and sign in.

**Do I need to know GA4 dimensions and metrics?**
No. You ask the question; Sprites picks the dimensions, runs the report and states what it queried.

**Can it change my GA4 property?**
Only two things, each behind an approval: it can create or archive audiences, and turn on ads personalization for a linked Google Ads account. Reports, events and settings are read-only.

**Which GA4 property does it use?**
The one connected in your Sprites business. If several are connected, name the property in the request.

**Does it handle ecommerce?**
Yes, including item-scoped breakdowns: revenue and units per product.

**Does it cover other channels?**
Yes. The same URL reaches Google Ads, Meta Ads, LinkedIn Ads, TikTok Ads, Reddit Ads, Microsoft Advertising,
Apple Ads, GA4, Search Console, Shopify, SEO and AI visibility, and Google Business Profile, for whatever is
connected in Sprites. See [ads-mcp-servers](https://github.com/sprites-ai/ads-mcp-servers).

**How much does it cost?**
The connector is included in every Sprites plan, and every plan starts with a short trial. See sprites.ai for current plans. GA4 charges its own media
cost as usual.

**The client says it has no tools, or every call is unauthorized.**
Remove the server, re-add it with exactly `https://mcp.sprites.ai/mcp`, and sign in again. Grants are bound to that one URL.

**How do I revoke access?**
Disconnect the connector in your client, or remove the connection in Sprites. The next tool call fails closed.
